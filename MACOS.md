# LiteChecker для macOS

Скачайте `LiteChecker-0.6.0-macOS.zip` для macOS arm64 или x86_64,
распакуйте и откройте `INSTALL.command`. Введите подписку и Telegram-настройки.
Python и Xray устанавливаются автоматически. Docker не требуется.

Данные и настройки: `~/Library/Application Support/LiteChecker`.
После успешной установки в исходной папке остаётся `LiteChecker.command` для управления.
Закрытие окна не останавливает проверки; используйте пункт остановки в меню.

Версия 0.6.0 требует новой установки. Старые тестовые установки автоматически
не переносятся и не удаляются. Если стандартная папка занята старой версией,
укажите отдельную пустую папку через `LITECHECKER_NATIVE_ROOT` при запуске установщика.
Для обновлений установленной версии используйте меню: канал принимает только macOS.
