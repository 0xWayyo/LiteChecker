# LiteChecker для macOS

Распакуйте `LiteChecker-0.6.0-macOS.zip` полностью. В папке будут:

- `INSTALL.command` — установка и меню управления
- `_app` — служебные файлы, открывать их вручную не нужно
- `НАЧНИТЕ-ЗДЕСЬ.txt` — эта инструкция

Откройте `INSTALL.command` и выберите «Установить и настроить».
Мастер последовательно попросит ссылку подписки, токен бота, ID чата и прокси,
если он нужен. Поддерживаются Mac с Apple Silicon и Intel.
Python и Xray устанавливаются автоматически. Docker не требуется.

Для запуска, остановки, просмотра событий, настроек и ручного обновления
снова откройте тот же `INSTALL.command`. Повторной установки не будет.
Закрытие окна не останавливает проверки; используйте пункт остановки в меню.

Данные и настройки: `~/Library/Application Support/LiteChecker`.
После успешной установки проверенные установочные файлы внутри `_app` удаляются;
в ней остаётся небольшой файл перехода к установленной программе.
Не удаляйте `_app` и не перемещайте `INSTALL.command` отдельно от неё.
Если файлы установки изменены или добавлены посторонние, очистка пропускается.

Версия 0.6.0 требует новой установки. Старые тестовые установки автоматически
не переносятся и не удаляются. Если стандартная папка занята старой версией,
укажите отдельную пустую папку через `LITECHECKER_NATIVE_ROOT` при запуске установщика.
Для обновлений установленной версии используйте меню: канал принимает только macOS.
