# LiteChecker для Windows

Поддерживаются Windows 10 и 11 x64. Распакуйте `LiteChecker-0.6.3-Windows.zip` в новую локальную папку и откройте `LiteChecker.bat`. Python и Xray устанавливаются автоматически; WSL и Docker не требуются.

При первом запуске откроется мастер: ссылка подписки → токен бота → ID чата → прокси Telegram. Каждый шаг показан до ввода: название поля, формат и доступные действия. Всё, что вы вводите, видно в терминале. Enter подтверждает значение; если оно уже сохранено, пустой ввод оставляет его без изменений. Ctrl+C отменяет настройку без частичной записи.

Telegram необязателен: оставьте токен пустым, чтобы продолжить без уведомлений. Прокси тоже необязателен; чтобы удалить уже сохранённый прокси, введите минус (-). При ошибке мастер попросит повторить только текущее поле. После настройки появится итог; проверки запускаются отдельно пунктом «1 — Запустить проверки».

В меню показан статус: 🟢 работает, 🔴 остановлен, 🟡 запускается или останавливается. Первый пункт меняется по статусу. Enter обновляет его; перед запуском, остановкой и проверкой обновлений показано текущее действие. В меню также доступны последний отчёт, настройки и диагностика сети. Закрытие окна не останавливает запущенный мониторинг. Сохранённые токены и ссылки программа повторно не показывает.

«Запустить проверки» сохраняет включённое состояние и добавляет один ярлык этой установки в автозагрузку текущего пользователя. После перезагрузки и входа в Windows меню открывается свёрнутым, а проверки и настроенные уведомления Telegram возобновляются без нажатия «1». «Остановить проверки» сохраняет остановку и убирает этот ярлык. Закрытие окна, выключение компьютера и обновление не равны ручной остановке. Во время сна и до входа в учётную запись проверки не выполняются.

После обновления со старой версии один раз откройте меню и запустите проверки. Если они уже работают, новое меню сохранит это состояние без запуска второго процесса. Добавленный вручную старый ярлык можно убрать из автозагрузки: LiteChecker создаёт свой. Политика Windows может запретить автозапуск; при ошибке программа покажет предупреждение. Не перемещайте установленную папку, пока включён автозапуск: сначала остановите проверки, а после переноса запустите их из нового места.

LiteChecker работает без прав администратора и изменений системных маршрутов, DNS, VPN или брандмауэра. Настройки и отчёты хранятся только в `_app\windows-state`; не пересылайте эту папку. Для поддержки отправляйте только `last-report.txt` или `last-diagnostics.txt`.

С версии 0.6.0 обновляйтесь через меню: настройки и ID сохраняются, переустановка не нужна. Для перехода с тестовых версий 0.2–0.5 остановите старый экземпляр через его меню и настройте новую копию отдельно. Не распаковывайте архив поверх прежней установки; старые тестовые данные и канал автоматически не переносятся и не сбрасываются.

Обновления из меню принимают только подписанный Windows-пакет. Технический архив `LiteChecker-0.6.3-windows-update-source.zip` нужен обновлятору; вручную открывайте обычный `Windows.zip`.
