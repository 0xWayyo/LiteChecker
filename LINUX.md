# LiteChecker для Linux

Скачайте `LiteChecker-0.6.0-Linux.zip` для Linux x86_64 или arm64 и распакуйте
в новую постоянную папку. Запустите `bash INSTALL.sh` и введите настройки.

Нужны Docker Engine и плагин Docker Compose; `docker info` должен работать
от вашего пользователя без sudo. Проверки выполняются в Docker; режима DIRECT
для Linux нет. Настройки, ключи устройства и отчёты остаются в папке установки.
Для управления повторно запустите `bash INSTALL.sh`; закрытие терминала не
останавливает контейнер.

Версия 0.6.0 устанавливается отдельно от старых тестовых версий. Перенос данных
и сброс старого канала не выполняются. Обновления через меню принимают только Linux.
